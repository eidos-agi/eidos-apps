# North star

Eidos Apps are Docker images. They will not fit in an applet viewer. Prims stay the files. Tools cite them. Surfaces are real pages. Agentic work stops at a human gate. Applets stay local workers with no listen-port.

The category for the first app is scene video: a shot you keep, not a clip you lucked into. The product name is Eidos Video. This repo is how you declare that it is an App — one image, one Dockerfile, one `app.json`.
